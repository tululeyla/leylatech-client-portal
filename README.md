# LeylaTech Client & Project Portal

A professional SaaS executive client and project management dashboard built with modern, framework-free Vanilla JavaScript and CSS Grid.

## 🚀 Live Demo
https://tululeyla.github.io/leylatech-client-portal/

## 🛠️ Tech Stack
- **HTML5:** Semantic markup (`<aside>`, `<header>`, `<main>`, `<section>`)
- **CSS3:** Custom Properties (Variables), CSS Grid, Flexbox, fully responsive layout
- **JavaScript (ES6+):** ES Modules (`api.js`, `ui.js`, `app.js`), `async/await`, Event Delegation
- **API:** JSONPlaceholder REST API (CRUD: GET, POST, DELETE, PATCH)

## ✨ Features
- **Core CRUD Engine:** Fetch initial client data on load, add new client records dynamically, delete records via event delegation.
- **Real-Time Status Updates:** Toggle client status badges (*Active* / *Pending*) instantly.
- **Instant Search Filter:** Filter clients and companies in real-time as you type.
- **Modular Architecture:** Clean separation of concerns (Data, UI, Controller layers).
